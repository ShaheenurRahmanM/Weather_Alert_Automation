# 🌦️ Free Weather Alert — Push Notifications + Settings UI

CallMeBot/WhatsApp turned out to be unreliable, so this **upgraded version** uses
**[ntfy.sh](https://ntfy.sh)** — a free, open-source **push notification** service that
just works. You get alerts as real phone notifications, and a **settings web page**
lets you customize everything without touching code.

### What you get
- ☀️ **Daily morning notification** with today's weather, rain chance, an **outfit tip**, and a **skincare tip tailored to your skin type**.
- 🌧️ **"Rain in ~15 minutes" alerts** whenever rain is about to start.
- 🎛️ **`settings.html`** — a visual UI to set location, skin type, units, times & toggles, with a one-click **"send test push"** button.
- 💸 **100% free**, runs 24/7 on **GitHub Actions**. No account, no API keys, no credit card.

## 🚀 Setup (~5 minutes, mostly tapping)

### 1. Install the ntfy app & pick a topic
1. Install **ntfy** (free): [Android](https://play.google.com/store/apps/details?id=io.heckel.ntfy) · [iPhone](https://apps.apple.com/us/app/ntfy/id1625396347) · or [web app](https://ntfy.sh/app).
2. Choose a **secret topic name** — treat it like a password, e.g. `kovai-weather-7h3k9q`.
3. In the app: **+ → Subscribe to topic →** type that exact name.

> A "topic" is just a private channel. Anything sent to `https://ntfy.sh/<your-topic>`
> pops up as a notification on every device subscribed to it.

### 2. Configure with the settings page
1. Open **`settings.html`** in your browser *(download it first — the in-app preview
   blocks network, so the "send test" button only works in a real browser)*.
2. Enter your topic, location, skin type, units, times & toggles.
3. Click **"Send test push"** → you should get a notification instantly. 🎉
4. Click **"Generate config.json"**, then **Copy** or **Download** it and replace the
   `config.json` in this project.

### 3. Put it on GitHub (free 24/7 scheduling)
1. Create a GitHub repo (can be **private**) and upload all files (keep the
   `.github/workflows/` structure).
2. *(Recommended)* To keep your topic private, **don't** commit it in `config.json`.
   Instead set it as a secret: **Settings → Secrets and variables → Actions → New secret**
   named `NTFY_TOPIC`. The workflows already read it. (If you'd rather just keep it in
   `config.json`, that's fine too — leave the secret empty.)
3. **Actions** tab → enable workflows → run **"Daily Weather Alert"** manually to test.

Done ✅ You'll now get the daily notification at **8 AM IST** and rain alerts automatically.

## 🎛️ Changing preferences later
Just re-open **`settings.html`**, change anything, regenerate `config.json`, and commit it.
The page remembers your last settings in the browser.

**To change the daily time**, also update the cron in `.github/workflows/daily-weather.yml`.
It's in **UTC**, so subtract 5h30m from your IST time:
| IST | UTC cron |
|-----|----------|
| 08:00 | `30 2 * * *` |
| 07:00 | `30 1 * * *` |
| 09:00 | `30 3 * * *` |

## ⚠️ Notes
- **Why ntfy over WhatsApp?** ntfy is an official, open-source push service with no fragile
  activation step — far more reliable than CallMeBot's free relay, and still completely free.
- **Privacy:** the free ntfy.sh server is public-by-topic, so use a long, random topic name.
  (For maximum privacy you can self-host ntfy, or set a username/password — optional.)
- **GitHub Actions cron** can drift a few minutes under load; the rain checker looks 30 min
  ahead to absorb that, so you still get warned in time.
- **Still want WhatsApp specifically?** The cleanest free WhatsApp route is Meta's official
  Cloud API (more setup). Say the word and I'll add a WhatsApp sender alongside ntfy.
